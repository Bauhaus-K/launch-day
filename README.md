# Launch Day — 재사용 로켓 발사 체험

2단 재사용 로켓의 발사부터 1단 부스터 착륙, 궤도 진입까지를 직접 체험하는 웹 기반 3D 시뮬레이션 게임입니다.
발사 전 Go/No-Go 점검, 카운트다운, Max-Q, 단 분리, 부스터 귀환, SECO까지 실제 미션 타임라인을 따라가며,
"진짜 같은 긴장감"과 "누구나 이해할 수 있는 쉬운 조작"의 균형을 목표로 합니다.

> 실제 재사용 로켓 발사 과정에서 영감을 받은 팬 메이드 시뮬레이션입니다.
> 게임에 등장하는 로켓 「헬리오스 9」와 회사 「오비탈 프런티어」는 가상 명칭이며, 특정 기업과 관련이 없습니다.

한국어 · English · 日本語 지원

## 주요 기능

- **발사 전 Go/No-Go 체크리스트** — 지상풍, 고층풍, 낙뢰, 액체산소 온도 등 7개 항목을 판단합니다. 이상을 놓치면 비행에 실제로 영향을 줍니다.
- **물리 기반 상승 비행** — 추력(고도별 비추력 보간), 고도에 따른 중력, 지수 대기, 공기저항, 연료 소모에 따른 질량 변화, 동압(q = ½ρv²)을 계산합니다.
- **Max-Q 구조 하중** — 스로틀을 줄이지 않으면 기체 스트레스가 쌓입니다.
- **1단 부스터 귀환·착륙** — 부스트백 → 재진입 연소 → 그리드 핀 조준 → 착륙 연소(호버슬램)로 바다 위 착륙선에 내립니다.
- **궤도 진입 판정** — 원지점·근지점을 실시간으로 계산하고, SECO 시점으로 정확도를 매깁니다.
- **점수·등급과 비행 리포트** — 고도·속도·동압 그래프, 부스터 궤적, 모드별 최고 기록 저장.
- **교육용 해설과 용어 사전** — 사건마다 "왜 이렇게 하는지"를 설명하고, 로켓 용어 19개를 정리했습니다.
- **합성 사운드** — 엔진음·효과음을 Web Audio API로 실시간 합성하며, 관제 음성은 브라우저 음성 합성을 사용합니다.
- **모바일 대응** — 터치 기기에서는 화면 조작 버튼이 나타납니다.

## 빠른 시작

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다 (Vite 8 요구 사항).

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고 난이도를 고르면 시작합니다.

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 타입 검사 후 프로덕션 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run test` | 단위·시뮬레이션 테스트 (Vitest) |
| `npm run lint` | ESLint 검사 |
| `npm run format` | Prettier 정리 |

## 난이도

| 모드 | 플레이어가 하는 일 |
| --- | --- |
| **관람 모드** | 없음. 비행 컴퓨터가 체크리스트부터 착륙까지 자동 진행하고, 해설을 보며 감상합니다. |
| **일반 모드** | 체크리스트 판단, 스로틀(특히 Max-Q), 주요 단계 승인, 부스터 착륙 연소 점화와 스로틀. 자세는 자동입니다. |
| **리얼 모드** | 스로틀·자세·엔진 정지(SECO)까지 전부 수동. 부스터도 직접 뒤집고 점화합니다. HUD의 권장값과 자세 고정 키(B/R)를 참고하세요. |

## 조작

| 키 | 동작 |
| --- | --- |
| `Space` | 다음 단계 승인 / 점화 / 체크리스트 GO |
| `H` | 체크리스트 NO-GO (홀드) |
| `W` `S` 또는 `Shift` `Ctrl` | 스로틀 증감 |
| `A` `D`, 방향키 | 자세(피치). 부스터가 엔진을 끄고 하강할 때는 그리드 핀 |
| `B` / `R` | 리얼 모드 부스터 자세 고정 — 부스트백 방향 / 역추진·착륙 자세 (다시 누르거나 A/D로 해제) |
| `C` | 카메라 전환 (발사대 / 추적 / 온보드 / 착륙선 갑판 / 부스터) |
| `T` | 시간 배속 (1x / 2x / 5x, 위험 구간에서는 자동으로 1x) |
| `M` | 소리 켜기/끄기 |
| `N` | 해설 자막 켜기/끄기 |
| `Esc` | 일시정지 |

터치 기기에서는 같은 기능의 화면 버튼이 표시됩니다.

## 미션 흐름

1. **발사 전 점검** — 항목별 GO/NO-GO 판단
2. **카운트다운** — T-60초부터, T-3초 엔진 점화
3. **이륙** — 발사탑 통과 후 피치 프로그램(중력 선회)
4. **Max-Q** — 최대 동압 구간, 스로틀 조절
5. **MECO** — 1단 엔진 정지 (부스터 귀환 연료 약 10% 확보)
6. **단 분리**
7. **SES** — 2단 점화, 페어링 분리
8. **부스터 귀환** — 플레이어가 부스터를 조종하는 동안 2단은 자동으로 궤도까지 비행
9. **궤도 진입** — SECO, 목표 200 km 원궤도 판정
10. **결과** — 점수·등급, 비행 리포트

## 점수 (100점)

| 항목 | 배점 | 기준 |
| --- | ---: | --- |
| 궤도 진입 정확도 | 35 | 원지점·근지점의 목표 고도 대비 평균 오차 |
| 남은 연료 (2단) | 15 | SECO 시점 잔여 추진제 |

| 부스터 착륙 | 25 | 착륙 성공 여부와 착지 위치·하강 속도·수평 속도·기울기 |
| 발사 전 체크리스트 | 10 | 놓친 이상, 불필요한 홀드 |

등급은 S(90+) · A(80+) · B(65+) · C(50+) · D, 궤도 진입에 실패하면 F입니다.

## 프로젝트 구조

```
src/
├─ main.ts        진입점 — 씬·UI·입력·미션 연결, 게임 루프 시작
├─ core/          게임 루프(고정 타임스텝), 시간 배속, 입력, 이벤트 버스, 최고 기록
├─ physics/       추력·중력·대기·항력·궤도 요소·낙하점 예측 (Three.js 비의존 순수 함수)
├─ rocket/        스택·부스터 상태와 분리 처리
├─ mission/       단계(Phase) 상태 머신, 자동 유도, 부스터 귀환 프로그램, 체크리스트, 점수, 비행 기록
├─ scene/         Three.js 씬 — 지구, 발사대, 로켓, 착륙선, 화염·연기(오브젝트 풀), 카메라
├─ ui/            HUD, 부스터 패널, 체크리스트, 해설, 용어 사전, 결과 화면·그래프, 터치 버튼
├─ audio/         엔진음·효과음 합성, 관제 음성
├─ i18n/          다국어 사전 (ko 기준, en·ja는 같은 키를 타입으로 강제)
├─ data/          제원·설정 상수 (매직 넘버는 모두 여기에)
└─ utils/
tests/            물리·미션·부스터·체크리스트·점수·다국어 테스트
```

설계 원칙:

- **로직과 렌더링 분리** — 미션·물리는 상태만 바꾸고, 씬·HUD·오디오는 상태를 읽거나 이벤트를 구독해 표현합니다.
- **고정 타임스텝** — 물리는 1/60초 단위로 갱신하고 렌더링은 보간합니다. 시간 배속은 스텝 횟수를 늘립니다.
- **플로팅 원점** — 카메라가 따라가는 기체를 원점으로 두어, 지구 규모 좌표에서도 정밀도를 유지합니다.
- **SI 단위** — 내부 계산은 m·kg·s·N만 쓰고, 표시할 때만 km, km/h 등으로 바꿉니다.

## 물리 모델과 수치

제원은 Falcon 9 Block 5의 공개 자료를 참고한 근사값이며, 근거를 `src/data/` 주석에 남겼습니다.
재미와 플레이 가능성을 위해 조정한 값은 "게임용 조정값"으로 표시되어 있습니다. 주요 단순화는 다음과 같습니다.

- 궤도면 위의 2D 비행 (지구 자전 미반영)
- 단일 스케일 높이(7.5 km)의 지수 대기 모델
- 부스터 재진입 손상은 공력 가열 지표(½ρv³)로 판정

## 테스트

```bash
npm run test
```

물리 함수 단위 테스트와 함께, 모드별 플레이어를 흉내 낸 **전체 미션 시뮬레이션 테스트**가 포함되어 있습니다.
관람 모드 자동 비행, 일반 모드에서 권장 시점에 직접 착륙, 리얼 모드에서 B/R 자세 고정으로 착륙하는 경우를 검증합니다.
미션 난수에 시드를 넣어 결과가 매번 같습니다.

## 저작권·크레디트

- 3D 모델과 텍스처는 Three.js 기본 도형과 코드로 절차적으로 생성하며, 외부 에셋을 쓰지 않습니다.
- 모든 소리는 코드로 합성하며 음원 파일을 쓰지 않습니다. 관제 대사는 새로 작성한 가상 대사입니다.
- 실제 기업의 로고·엠블럼·폰트·미션 영상/음성은 사용하지 않습니다.
